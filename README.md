# Type Natural Korean: Keyboard

A custom iOS keyboard for Korean learners and expats. It types Korean (두벌식) and English fully offline, with no Full Access required — and when you want a second opinion, tap Check to catch grammar mistakes in what you wrote, or Translate to turn an English sentence into Korean in the tone you choose.

Coming soon to the App Store.
